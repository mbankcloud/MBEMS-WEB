# Bank Election Management System (BEMS)

Production-ready Next.js + Supabase election management for cooperative banks.

## Quick Start

```bash
npm install
cp .env.example .env.local   # fill in Supabase credentials
# Run SQL migrations in Supabase dashboard (supabase/migrations/)
npm run dev
```

## Roles: Super Admin → Director → Agent
## Login: Single /login page, redirects by role
